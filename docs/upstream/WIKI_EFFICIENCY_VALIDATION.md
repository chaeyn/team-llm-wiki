# 위키 스킬 진입 지침 측정 (상류 참고 자료)

상류 내부 팀의 `o200k_base` 측정값이다. **스킬 진입 지침만** 비교한 것으로,
참고 문서 읽기·전체 작업·실제 청구 토큰을 포함하지 않는다. 현재 배포본을
새로 측정한 수치도 아니다.

| 항목 | 이전 | 이후 | 감소율 |
| --- | ---: | ---: | ---: |
| wiki-update 진입 지침 | 7,434 | 551 | 92.6% |
| wiki-reader 진입 지침 | 1,071 | 249 | 76.8% |

상세 지침은 필요한 단계에서 참고 자료로 읽으므로 전체 비용은 작업에 따라
달라진다. 새 문서 본문 작성에 필요한 토큰은 여전히 필요하다.
